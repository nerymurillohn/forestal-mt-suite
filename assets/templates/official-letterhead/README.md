# Official Letterhead Templates

## Files

| File | Description |
|------|-------------|
| `docx/forestal-mt-letterhead.docx` | Editable Microsoft Word template with official header/footer graphics (use for DOCX/Google Docs outputs). |
| `pdf/forestal-mt-letterhead.pdf` | Reference PDF showing the rendered letterhead; use for print-ready exports or visual QA. |

## Usage

1. Open the DOCX template and immediately “Save As” for your new document to preserve the master copy.
2. Apply the formatting rules from `docs/brand/typography.md` for titles, headings, body text, etc.
3. When delivering final outputs:
   - DOCX: export/save directly from the template.
   - Google Docs: import the DOCX template, keep header/footer locked, then apply the typography styles.
   - PDF: export from the edited DOCX or reference the provided PDF to ensure visual parity.

## Notes

- Header and footer graphics are embedded—no need to reinsert images each time.
- If the letterhead artwork changes, update the DOCX and regenerate the PDF here so all future documents stay aligned.
